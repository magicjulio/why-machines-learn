{{ experiment.title }}

Classic Hebbian Hopfield setup with two stored memories (MNIST digits 5 and 8). Add noise to one memory and inspect asynchronous recall sweep by sweep.

Controls

Press Run Hopfield Recall to simulate noisy recall dynamics.

Update Style

Each sweep updates neurons one-by-one in sequence. That is asynchronous update, not all pixels simultaneously.

Energy Function

Recall tends to reduce E = -0.5 s^T W s. Lower energy means a more stable state, but not always an exact stored memory.

Why Only 5 & 8

Keeping memory load tiny makes attractor behavior easier to see and avoids capacity issues hiding the theory.
