Recreate the notebook’s PCA pipeline: compute the covariance matrix, extract eigenvectors, and project the four-dimensional Iris measurements into a lower-dimensional space.

Controls

Press Run PCA to project the Iris data and inspect how much variance the leading components explain.

Covariance Matrix

PCA starts from X^T X / (n - 1), which captures how the flower measurements vary together across the dataset.

Eigenvectors

The top eigenvectors define the new axes. Their entries, called loadings, show which original features push each principal component the most.

Projection

Projecting onto the first two or three principal components preserves as much variance as possible in a smaller space you can actually see.
